## 🧩 Featured Work

### 1. CloudPixels — Product Image Readiness

**HackIndia Pixels to Products / Cloudinary AI Hackathon**

Contributing to a product-image analysis workflow for e-commerce listings. My backend work includes a Next.js API route that accepts an uploaded image, sends it to an OpenAI vision model for analysis, and returns structured findings about visible image issues and their severity.

- **Backend concepts:** File upload handling, image-to-base64 conversion, API responses, JSON parsing, error handling, and environment variables
- **Tech:** Next.js, JavaScript, OpenAI API
- **Status:** Backend pull request is open for review
